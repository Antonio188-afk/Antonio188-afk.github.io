I worked on making my very own Ethernet cable in class by myself. My teacher was there, supervising and watching over us to make sure we all did it right, and even though not everyone did, I got it right on the first try! Overall, doing this project taught me some patience because we had to feed wire through small holes to make it work, and taught me how to make an Ethernet cable. Now I can use this project for future help one day. Some tools used to do so were specific tools to cut, strip, terminate, and test your connections for reliability. I learned how to make an Ethernet cable. Some challenges faced were diving the tiny wire inside the cord to make the cable.
